## 3. Library docs

### curl_cffi (lexiforest/curl_cffi, MIT; installed 0.16.3, latest 0.17.0)
- Python binding for a curl-impersonate fork. Impersonates browsers' TLS/JA3 and HTTP/2 fingerprints. `impersonate="chrome"` tracks the newest; pin with a version, e.g. `chrome124`.
- Sync `Session` and asyncio `AsyncSession` (`async with AsyncSession() as s: await s.get(...)`).
- WebSockets: "WebSocket handshakes go through your session, so they use the same browser impersonation (TLS/JA3 fingerprint), proxies, cookies and headers as your HTTP requests." Fragment reassembly, timeouts and retries, permessage-deflate.
- HTTP/3 with impersonation (`http_version="v3"`). http and socks proxies.
- Custom fingerprints: `ja3=`, `akamai=`, `extra_fp=`.
- Since 0.15.1, `curl-cffi update` fetches newer fingerprints from impersonate.pro without a new release; Safari, Chrome and Firefox updates are free, others are commercial.
- Targets doc: "Chrome 151 and 152 have separate Windows targets (chrome151, chrome152) and macOS targets (chrome151_macos, chrome152_macos). The chrome alias selects the Windows profile. Firefox 153, 154 and 155 do not include dedicated HTTP/3 fingerprints." Suffix `a` (e.g. chrome133a) = A/B-test variant.
- Ecosystem: Scrapy integrations, requests and httpx adapters. A Node binding (`impers`) exists.

### httpcloak (sardanioss/httpcloak, MIT; Go core, PyPI/npm/NuGet bindings; tested 1.7.4)
- "Go HTTP client with browser-identical TLS/HTTP2 fingerprinting… JA3/JA4, Akamai fingerprint, header order. Supports HTTP/1.1, HTTP/2, HTTP/3, sessions, cookies, and proxies." Created 2025-12-28.
- Emulates TLS (JA3/JA4, GREASE, post-quantum X25519MLKEM768, ECH), HTTP/2 SETTINGS/WINDOW_UPDATE/priorities, QUIC parameters, HTTP/3 GREASE, the TCP/IP stack (TTL, MSS, window), Sec-Fetch and client-hint coherence, header order, cookie persistence.
- Presets per browser, version and OS, e.g. chrome-155-windows, chrome-158-macos, chrome-157-android, firefox-148-windows, safari-26-ios; `chrome-latest-*` aliases track the newest shipped Chrome (158).
- `describe_preset` / `load_preset_from_json`: build any fingerprint from JSON, including from a tls.peet capture.
- Connection lifecycle: Refresh (drop connections, keep tickets and cookies, like a tab reload), Warmup (load the page and subresources like a browser), Fork (parallel tabs sharing cookies and TLS state), session save and restore to JSON, HTTP/2 connection-age limit (5 minutes by default).
- Proxies: HTTP CONNECT, SOCKS5, SOCKS5 UDP ASSOCIATE and MASQUE for HTTP/3, runtime proxy switching, speculative TLS.
- Python API: `httpcloak.Session(preset=..., proxy=..., timeout=..., http_version=...)`, `session.get/post/get_stream`. The docs show no asyncio API for Python (Node and .NET have async methods).
- WebSocket: the docs only mention that the WebSocket upgrade starts as an HTTP/1.1 request. There is no WebSocket client API in the docs for any binding.
- Native library prebuilt for Windows 10+, macOS 12+, Linux glibc; no musl.
